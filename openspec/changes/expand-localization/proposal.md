## Why

English and Chinese are the only available interface languages. Users need matching app and website translations, discoverable localized documentation, and clear ways to contribute improvements.

## What Changes

- Add Spanish, Japanese, Korean, French, German, Brazilian Portuguese, and Russian to the TUI and all website pages.
- Generalize locale resolution, instant settings changes, and CLI language selection.
- Provide an accessible website language menu, localized metadata, reciprocal hreflang, sitemaps, and localized errors.
- Invite issue reports, translation improvements, and pull requests through unobtrusive app and website links.

## Capabilities

### New Capabilities
- `expanded-localization`: Shared language coverage, selection, translation invariants, and website search discovery.
- `contribution-discovery`: App and website affordances that guide users to contribution instructions and pull requests.

### Modified Capabilities

None.

## Impact

App i18n, config, TUI settings/help, CLI and documentation; sibling ccmux-website routing, catalogs, navigation, SEO, tests, and nginx localized error handling. No daemon protocol or runtime translation service changes.
